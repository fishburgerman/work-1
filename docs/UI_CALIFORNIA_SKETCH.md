# UI デザイン — California Sketch（Warm Minimal Workspace）

作成日：2026-11-16（Coastal Line から変更。ダークモードは Midnight Calm を継承）

キーワード：Calm・Natural・Airy・Human・Minimal・Warm。長時間使っても疲れにくく、仕事が少し心地よくなる業務アプリ。

## 1. 仕組み

各画面は Tailwind の `navy-*`・`slate-*`・状態色のクラスで書かれている。クラスが参照する CSS 変数（`src/index.css` の `@theme`）を置き換えて、全画面を一度に同じデザインにする。色の定義は `index.css` の1か所だけで、重複定義・優先順位の競合はない（`.dark` はダークモードのときだけ上書き）。

## 3. 形・文字・動き

| 項目 | 値 |
| --- | --- |
| カード・ダイアログの角丸 | 12px |
| ボタン・入力欄の角丸 | 9px |
| 影 | `0 1px 2px rgb(52 61 56 / 0.04)`（カード）。区切りは 1px の境界線（浮いたカードにしない） |
| 本文の書体 | `Inter`（入っていれば）→ システムフォント → ヒラギノ角ゴ・Noto Sans JP・游ゴシック UI・メイリオ。外部の Web フォントは読み込まない（CSP で外部への通信を禁止しているため） |
| 手書き風の書体 | ロゴ「WorkCore」だけ：`Bradley Hand`（macOS）・`Segoe Print`（Windows）など OS にある書体。無い環境では通常の書体。本文・入力欄・表には使わない |
| 太さ | Regular（400）と Medium（500）が中心。bold は 600 |
| 見出し | ページ 20px・セクション 15px |
| 動き | ボタンのホバー 150ms・ダイアログ 180ms・通知 150ms・メニュー 150ms。バウンスなし。「動きを減らす」設定ではほぼ無効 |

## 4. 手描きのラインアート（`src/ui/Sketch.tsx`）

線幅 1.4〜1.8px・塗りなし・端は丸く。制御点を少しずつずらし、一部の線は少しずらして2回なぞる（中程度の手描き感）。色はセージ（`--color-lineart`）、太陽だけテラコッタ。アニメーションなし。装飾なので `aria-hidden`。

| 使う場所 | 内容 |
| --- | --- |
| ロゴ（サイドバー・スマホのヘッダー）・favicon | 太陽と2本の波 |
| ダッシュボードの見出しの右 | 波線・太陽・葉の小枝（スマホでは表示しない） |
| ウェルカム（使い方ガイド） | 太陽・波・小枝の小さな印 |
| 空データの表示（30 か所の共通部品） | アイコンを囲む手描きの輪 |
| サイドバーの下 | 小さな波線と葉（折りたたみ時は表示しない） |
| ナビゲーションのアイコン | 既存の lucide（線幅 1.75 に統一）。選択中は淡いグリーンの背景 |

業務データの背後・表・入力欄・ダイアログの内部には置かない。

## 5. 変更していないもの

機能・データ構造・保存処理・テストデータ・画面遷移・操作方法。テーマ（ライト／ダーク／端末設定）の切り替えは従来どおり、既定はライト。
