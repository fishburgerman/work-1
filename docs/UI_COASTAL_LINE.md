# UI デザイン — Coastal Line（California Coastal Minimalism × macOS）

作成日：2026-11-16（Mac Native × Midnight Calm から変更。ダークモードは Midnight Calm を継承）

## 1. 仕組み

各画面は Tailwind の `navy-*`・`slate-*`・状態色のクラスで書かれている。クラスが参照する CSS 変数（`src/index.css` の `@theme`）を置き換えて、全画面を一度に同じデザインにする（60 ファイル・約 2,500 か所のクラスは書き換えない）。色の定義は `index.css` の1か所だけで、重複定義・優先順位の競合はない（`.dark` はダークモードのときだけ上書きする）。

## 2. パレット（ライト・既定）

| 役割 | 指定 | 実装 | 備考 |
| --- | --- | --- | --- |
| メイン背景 | `#F8F7F4` | `slate-50` | |
| サイドバー | `#F2F1ED` | `slate-100`・`sidebar` | |
| カード | `#FFFFFF` | `white` | |
| メイン文字 | `#202A32` | `slate-900` | 背景に対して 13.6:1 |
| サブ文字 | `#6D7880` | 文字は `#626D75`（`slate-400`）、アイコン・プレースホルダーは `#6D7880` | `#6D7880` は背景 4.22:1・サイドバー 4.00:1 で、文字の基準（WCAG AA 4.5:1）に届かない |
| アクセント | `#7296A5` | `navy-500`：フォーカス・アイコン・選択の印・ラインアート。文字・主要なボタンは `navy-600〜800`（`#4E6E7D`〜`#3D5663`。背景・サイドバー・薄い色の行でも 4.5:1 以上） | `#7296A5` は白に対して 3.2:1（文字には使えない） |
| ボーダー | `#E6E7E5` | `slate-200` | |

アクセントは主要なボタン・選択状態・フォーカス・リンクだけに使う。状態色（成功・警告・エラー）は彩度を抑えた濃淡。

## 3. 形・文字

| 項目 | 値 |
| --- | --- |
| カード・ダイアログの角丸 | 12px（`rounded-2xl`） |
| ボタン・入力欄の角丸 | 8px（`rounded-lg`） |

| 本文・補足 | 13〜14px / 12〜13px |
| 太さ | Regular（400）と Medium（500）が中心。bold は 600 |

## 4. ラインアート（`src/ui/CoastalLine.tsx`）

| 項目 | 内容 |
| --- | --- |
| 形式 | インラインの SVG（画像ファイル・ライブラリなし）。`fill: none`・線幅 1.25px（`vector-effect: non-scaling-stroke` で拡大縮小しても同じ太さ）・端は丸く |
| 色 | `--color-lineart`：グレーブルー `rgb(114 150 165 / 0.55)`。ダークでは `rgb(182 205 215 / 0.32)` |
| 線 | 制御点を少しずつずらし、太陽の円は少しはみ出して閉じる、波は途切れさせる（手描きの調子）。アニメーションなし |
| ダッシュボード | 見出しの右の余白に、岬・海岸線・波・遠くの山並み・太陽とその映り込み（`CoastalHorizon`）。スマホでは表示しない |
| サイドバーの下 | 小さな波と水平線の太陽（`SidebarWaves`）。折りたたみ時は表示しない |
| その他の画面 | 装飾なし（表・フォーム・ダイアログの内部にも入れない） |
| アクセシビリティ | 装飾のため `aria-hidden`（読み上げない） |

機能・データ構造・保存処理・テストデータ・画面遷移・操作方法。テーマ（ライト／ダーク／端末設定）の切り替えは従来どおり。既定はライト。
