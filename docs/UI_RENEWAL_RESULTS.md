### 指定の色からの調整（アクセシビリティのため）

| 指定 | 調整 | 理由 |
| --- | --- | --- |
| Muted Text `#85858B` | 補足の文字は `#9E9EA3`／`#A1A1A6`。`#85858B` はアイコン・プレースホルダー・無効の表示に使用 | `#85858B` は面 `#2C2C2E` に対して 3.8:1 で、文字の基準（WCAG AA 4.5:1）に届かない |
| 主要なボタンの文字 | セージ `#8FA89A` の地に、白ではなく `#1C1C1E` の文字（6.7:1） | 白の文字は 2.4:1 |
| ライトモード | アクセントは濃いセージ（`#3A5143` など）、背景 `#F5F5F7`・面 白 | ライトでも文字 4.5:1 以上 |

すべての文字と背景の組み合わせをスクリプトで確認し、E2E の axe（WCAG 2.2 AA）で全画面・主要なダイアログを両モードで検査した。
